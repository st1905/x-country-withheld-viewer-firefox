Installation
1. Extract the ZIP.
2. Open Firefox and visit about:debugging#/runtime/this-firefox.
3. Click Load Temporary Add-on.
4. Select the extracted manifest.json.

5. Now you can browse X accounts with the Country Withheld Tweets.

6. Adapted from https://github.com/yusufky63/x-country-withheld-viewer

See FIREFOX-INSTALL.txt for more details.
